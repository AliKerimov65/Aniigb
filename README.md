# Спортивный зал 24×46 м для Арктической зоны — ПСПК «МАРХИ»

Интерактивная 3D-концепция быстровозводимого спортивного зала для Дудинки (Красноярский край)
на пространственной стержневой системе ПСПК «МАРХИ» с пространственным фундаментом-«зеркалом».

## Страницы проекта

| Файл | Содержание |
|------|-----------|
| `index.html` | Главная 3D-модель: фундамент-зеркало h=2,12 м, колонны △700/△1200, вспарушенное покрытие f=0,9 м, вспом. блок 3 эт., входная группа со скульптурой, щиты подполья, оси и размеры |
| `logistics.html` | Модель логистики Красноярск → Дудинка (анимация маршрута) |
| `assembly.html` | Мультипликация сборки — последовательность монтажа каркаса |
| `node.html` | Узел-коннектор МАРХИ (одноболтовой) — детальная модель |
| `drawings.html` | Чертежи: план, фасады, разрез (плоская графика) |
| `calc.html` | Расчётная схема: нагрузки, снеговой район VI (Дудинка) |
| `render.html` | Архитектурная визуализация день/ночь: облачное небо, ночная подсветка, фасады с панелями изнутри каркаса, ленточное остекление, витраж входа, мачты освещения |

## Запуск

Все страницы — статические HTML (Three.js 0.160 по CDN). Достаточно открыть `index.html`
в браузере либо включить GitHub Pages: **Settings → Pages → Branch: main**.
