# Спортивный зал 24×46 м для Арктической зоны — ПСПК «МАРХИ»

Интерактивная 3D-концепция быстровозводимого спортивного зала для Дудинки (Красноярский край)
на пространственной стержневой системе ПСПК «МАРХИ» с пространственным фундаментом-«зеркалом».

## Страницы проекта

| Файл | Содержание |
|------|-----------|
| `index.html` | Главная 3D-модель: фундамент-зеркало h=2,12 м, колонны △700/△1200, вспарушенное покрытие f=0,9 м, вспом. блок 3 эт., входная группа, щиты подполья, оси и размеры |
| `logistics.html` | Анимация логистики: Красноярск → Дудинка (ж/д + Енисей), раскладка по грузам |
| `assembly.html` | Мультипликация монтажа: пошаговая сборка каркаса |
| `node.html` | Узел-коннектор МАРХИ: одноболтовое соединение, деталировка |
| `drawings.html` | Плоские чертежи: план, разрез, фасад с размерами |
| `calc.html` | Расчётная схема: нагрузки, снеговой район VI, пролёт 24 м |
| `render.html` | Архитектурная визуализация день/ночь: голубое облачное небо, ночная подсветка, фасады с панелями изнутри каркаса, ленточное остекление по нормам, витраж входа, мачты освещения |

## Ключевые параметры концепции

- Здание 24 × 46 м, поле мини-футбол 38 × 19 м, вспом. блок 5 × 24 м (3 этажа)
- Пространственный фундамент — зеркало покрытия: h = 2,12 м, пятно 27 × 48 м,
  проветриваемое подполье как теплоотсечка мерзлого грунта
- Чистый пол +2,400 (сэндвич-панели по верхнему поясу фундамента)
- Колонны треугольные △700 / △1200, шаг 6 м, +2,400 … +12,400
- Покрытие ПСПК 24 × 46 м со вспарушиванием f = 0,9 м (f/l ≈ 1/27)
- Ограждение: сэндвич-панели с внутренней стороны каркаса; потолок — по нижнему поясу плиты
- Остекление: ленточное +10,20…+12,00 (≈165 м², ≈1/6,5 поля), витраж входа 11,3 × 9,6 м
- Снеговой район VI (Дудинка), Крайний Север
