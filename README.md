# Aniigb — Арктический спортзал 24×46 м на системе МАРХИ (ПСПК)

Интерактивная концепция быстровозводимого спортивного зала для Арктической зоны (Дудинка, Красноярский край) на пространственной стержневой системе МАРХИ / ПСПК (одиноболтовые узлы, трубы Ø60×3…Ø146×10, модуль сетки 3×3 м).

Открыть `index.html` в браузере (нужен интернет для CDN three.js). Все страницы адаптированы под смартфон (safe-area, сворачиваемые панели).

## Страницы

| Файл | Содержание |
|---|---|
| `index.html` | Главная 3D-модель: зал 24×46 м, блок ФСО 5×24 м (3 этажа), зеркальный пространственный фундамент с проветриваемым подпольем, арочное покрытие ПСПК f=0.9, входная группа с лестницей, поручнями и скульптурами спортсменов |
| `logistics.html` | Логистика: завод (Красноярск) → контейнеры 20 фут → автотранспорт → причал → Енисей ≈1989 км → порт Дудинка → площадка (кадастр 84:03:0020005:1840). Режим мультипликации — 9 шагов цепочки поставки |
| `assembly.html` | Мультипликация монтажа: 12 этапов от фундамента до подъёма флага |
| `node.html` | Типовой узел МАРХИ крупным планом: сфера, болт 10.9, поводковая втулка, вкладыш, труба; разборка узла слайдером |
| `drawings.html` | Плоские чертежи (SVG): план, разрезы 1-1 и 2-2, оси и размерные цепочки |
| `calc.html` | Расчётная схема с нагрузками: Дудинка — снеговой район VI (Sg=3.0 кПа, расч. 4.2 кПа), ветровой IV; онлайн-пересчёт по СП 20.13330.2016 |
| `render.html` | Архитектурная визуализация день/ночь: голубое облачное небо, звёзды и луна ночью; внутренняя подсветка зала и витража, 6 мачт 16 м с прожекторами; фасады — панели изнутри каркаса, ленточное остекление +10,20…+12,00 (≈165 м²), витраж входа 11,3×9,6 м, потолок по нижнему поясу ПСПК |

## Ключевые параметры

- Здание: 24×46 м, h колонн 10 м, покрытие ПСПК 2.12 м, вспарушивание f=0.9 м
- Фундамент: зеркальная пространственная плита 27×48 м, подполье 2.12 м проветриваемое (теплоотсечка мерзлоты), регулируемые ветро-снеговые щиты (зазор 350 мм зимой)
- Колонны: стальные коротыши △700 (Ø114×5) и △1200 по периметру
- Сталь: ≈76 т; смета (ТЭП): ≈84.5 млн ₽
- Нагрузки: снег 4.2 кПа расч., давление на грунт ≈6.9 кПа (мерзлота не оттаивает)

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000/index.html
```
